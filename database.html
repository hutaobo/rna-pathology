Database Overview

RNA-Pathology: a schema-driven framework for spatial molecular pathology data.

About RNA-Pathology

RNA-Pathology is an open research database designed to organize, standardize, and contextualize spatially resolved molecular pathology data, with emphasis on RNA-based spatial technologies.

Core Design Principles

  • **Schema-first design:** data structures are defined before data ingestion.
  • **Spatial context as a first-class entity:** spatial information is not auxiliary metadata.
  • **Modality-agnostic, pathology-aware:** accommodate multiple technologies with consistent interpretation.
  • **Reproducibility over volume:** prioritize clarity, provenance, and reproducibility over sheer data volume.

Access Model (Planned)

RNA-Pathology will support public datasets, controlled-access datasets, and programmatic access via APIs (planned for future releases).

Project Status

Early public architecture phase focused on schema definition and documentation. More datasets and features are being added continuously as the project evolves.

RNA-Pathology is an open research initiative. Usage of data, benchmarks, and materials is subject to defined terms.
