## What SPatho is

SPatho is a workflow layer for AI-assisted spatial pathology analysis.
It currently supports:

- cluster evidence generation
- OpenAI-assisted or heuristic cluster annotation
- dendrogram-guided tissue structure discovery
- H&E-aware overlay generation
- structure-level pathology review
- case-level HTML reporting
- artifact manifests for downstream delivery and audit
