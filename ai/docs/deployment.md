# Deployment Modes

SPatho is being shaped to support three practical deployment modes.

## 1. Local workflow execution

This is the current community-oriented path.

Typical pattern:

- install `spatho`
- provide a local OpenAI API key
- run workflows on local or lab-managed infrastructure
- review generated reports and artifacts

Best for:

- academic labs
- pilot studies
- method development

## 2. Managed service delivery

In this model, the product owner or service team runs SPatho for the customer.

Typical pattern:

- customer provides data
- workflows are run centrally
- the customer receives reports and artifact bundles

Best for:

- first commercial projects
- low-friction customer onboarding
- proof-of-value engagements

## 3. Private deployment

In this model, the customer runs SPatho in their own controlled environment.

Typical pattern:

- private infrastructure
- customer-managed credentials
- organization-specific workflow governance
- stricter data handling controls

Best for:

- biotech and pharma teams
- clinical-adjacent programs
- sensitive customer environments

## Recommendation

The current recommended order is:

1. start with local and managed delivery
2. validate the commercial offering with real users
3. add private deployment for higher-governance customers
